# currency_converter
Currency Converter 💱

A responsive and interactive Currency Converter Web Application built using HTML, CSS, and JavaScript.
This project converts currencies dynamically using exchange rate API data and updates country flags automatically based on selected currencies.

🚀 Features
<br>
✅ Real-time currency conversion
<br>
✅ Dynamic exchange rate fetching using API
<br>
✅ Country flag updates
<br>
✅ Responsive UI design
<br>
✅ Currency dropdown selection
<br>
✅ Input validation
<br>
✅ Interactive user interface
<br>
✅ Beginner-friendly clean code structure
<br>

<br>

<br>

<br>

<br>
Exchange Rate API
<br>

<br>

⚙️ How It Works
User enters an amount.
Selects source currency.
Selects target currency.
Application fetches live exchange rates using API.
Converted value is displayed instantly.
Country flags update dynamically according to selected currencies.

🌐 API Used
<br>
Exchange Rate API : Used for fetching live currency conversion rates.

Currency API by Fawaz Ahmed
